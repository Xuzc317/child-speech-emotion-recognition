# 跨数据集儿童语音情绪识别 —— 数据构造方案

> 创建: 2026-06-05 | 目标: 构造一个类别均衡、质量可控的儿童语音情绪数据集，提升模型在非表演型场景下的鲁棒性与精度

---

## 1. 背景

### 当前瓶颈

现有 FAU Aibo（自发性儿童德语）域内训练结果：

| Exp | 数据集 | WA | UAR | 主要问题 |
|-----|--------|-----|-----|---------|
| Exp5 | FAU Aibo 域内 | 66.36% | 56.35% | neutral 占比 59%，angry/happy→neutral 混淆占 63% |
| Exp4 | C-BESD→FAU 零样本 | 19.56% | 23.83% | 表演型模型无法泛化到自发性 |

**根因**：
1. FAU 类别严重不平衡（neutral 58.9%，sad 0%）
2. 自发性 angry/happy 样本不足，且与 neutral 的声学边界模糊
3. 表演型（C-BESD）与自发性（FAU）之间的分布偏移过大，无法直接混合训练

### 本方案目标

构造一个**4 类均衡、以非表演型为主、经过跨数据集分布验证**的儿童语音情绪训练集，目标：
- 每类样本数配平（目标 ~700/类）
- 跨数据集情绪定义一致（通过声学特征分布验证）
- 保留 FAU 原有测试集作为独立评估标准

---

## 2. 方案总览（4 个 Phase）

```
Phase 1: 跨数据集情绪分布验证（先跑实验）
  ├── 对每个候选数据集、每种情绪，提取 F0/RMS/时长统计量
  ├── 验证"同情绪跨数据集"的声学特征区间是否重叠
  ├── 验证"同数据集不同情绪"是否可区分（类间 FD > 类内 FD）
  └── 输出：每个数据集-情绪对的"合格/不合格"判定

Phase 2: 数据清洗与配平
  ├── FAU 二次清洗：每类保留 700 条高质量样本（RMS/F0/标注一致性筛选）
  ├── 新自发数据：补充 FAU 缺失的类别（尤其是 sad）
  ├── C-BESD sad：如 Phase 1 验证通过，作为自发性 sad 的 fallback 补充
  └── 目标：4 类 × 700 = 2,800 条训练样本

Phase 3: 训练与验证
  ├── 训练集：清洗后的混合数据集（2,800 条）
  ├── 测试集：FAU 原始 test set（3,389 条）+ C-BESD original test set（540 条）
  ├── 对比实验：混合数据集 vs 纯 FAU vs 纯 C-BESD
  └── FD 监控：训练前后各目标域的 FD 变化

Phase 4: 跨数据集音频标准化
  ├── 统一预处理：16kHz resample + peak normalization + 4s 截断/填充
  ├── 说话人独立划分（MD5 hash）
  └── 4 类标签映射：angry / happy / neutral / sad
```

---

## 3. Phase 1：跨数据集情绪分布验证（最关键）

### 3.1 验证目标

在合并任何数据之前，先回答核心问题：**"angry"在 FAU 和在 C-BESD（以及新数据集）中是同一个 angry 吗？**

### 3.2 提取特征

对每个数据集的每条样本：

| 特征 | 计算方式 | 物理含义 |
|------|---------|---------|
| F0 mean | 整条语音 F0 均值 | 整体音高水平 |
| F0 std | 整条语音 F0 标准差 | 音高变异性 |
| F0 range (P95-P5) | 95% 分位 − 5% 分位 | 音高动态范围 |
| RMS mean | 整条语音 RMS 均值 | 整体响度 |
| RMS std | 整条语音 RMS 标准差 | 响度变异性 |
| Duration | 有效语音时长（去除首尾静音） | 持续长度 |

### 3.3 验证规则

**规则 1：同情绪跨数据集特征区间重叠**

```
对每种情绪 E:
    FAU[E] 的 F0_mean 分布区间 [μ_FAU−2σ, μ_FAU+2σ]
    C_BESD[E] 的 F0_mean 分布区间 [μ_CB−2σ, μ_CB+2σ]
    如果两个区间重叠 > 50% → 通过
    否则 → 标记为"E在该数据集对中不一致"
```

**规则 2：同数据集不同情绪可区分性**

```
对每个数据集 D:
    FD(angry, neutral) 应该 > FD(angry, happy)
    FD(happy, sad) 应该 > FD(happy, neutral)
    如果某对情绪的 FD 小于跨情绪平均 FD 的 50% → 标记
```

**规则 3：跨数据集情绪排序一致性**

```
在每个数据集内:
    F0_mean(angry) > F0_mean(happy) > F0_mean(neutral) > F0_mean(sad)
    RMS_mean(angry) ≈ RMS_mean(happy) > RMS_mean(neutral) > RMS_mean(sad)
    如果排序不一致 → 标记为"情绪定义可能不同"
```

### 3.5 验证结论 → 决策

| 验证结果 | 决策 |
|---------|------|
| 全部通过 | 可以直接合并所有数据 |
| 某数据集某情绪不通过 | 剔除该数据集-情绪对 |
| 表演型 sad 通过（F0/RMS 在 sad 理论区间内） | 可以用于补充自发性 sad 缺失 |
| 表演型 sad 不通过 | 放弃表演型 sad，只用自发性数据 |

## 4. Phase 2：数据清洗与配平方案

### 4.1 FAU 清洗

原始 FAU 训练集（≈11,600 条）→ 清洗后保留约 2,100 条（3 类 × 700）。

**清洗标准**：

| 指标 | angry 保留标准 | happy 保留标准 | neutral 保留标准 |
|------|---------------|---------------|-----------------|
| F0 mean | 200–600 Hz | 180–500 Hz | 150–350 Hz |
| RMS | > neutral 均值的 30% | > neutral 均值的 20% | > 全局 20% 分位 |
| 标注一致性 | ≥ 3/5 标注者一致 | ≥ 3/5 | ≥ 3/5 |
| 时长 | 1.5–4.0s | 1.5–4.0s | 1.5–4.0s |

对 neutral 额外筛选：保留 RMS 分布与 angry 子集最接近的 700 条（"活跃的中性"——更接近真实交互），而非随机选取。这有助于减少 angry→neutral 混淆。

**清洗后 FAU**：

| 情绪 | 保留数 | 舍弃数 |
|------|--------|--------|
| angry | 700 | ~1,200 |
| happy | 700 | ~2,200 |
| neutral | 700 | ~6,300 |
| sad | 0 | 0 |
| **合计** | **2,100** | **~9,700** |

### 4.2 新自发数据补充

| 需要补充 | 目标数量 | 来源 |
|---------|---------|------|
| angry | 0（FAU 已有 700） | — |
| happy | 0（FAU 已有 700） | — |
| neutral | 0（FAU 已有 700） | — |
| sad | 700 | 待找 |

**sad 的获取优先级**：
1. **自发性儿童 sad 数据集**（最理想——你负责找）
2. **C-BESD sad（696 条）**——前提是 Phase 1 验证通过
3. **其他表演型儿童 sad 数据集**——前提是 Phase 1 验证通过

### 4.3 C-BESD 的角色

**C-BESD 不作为训练数据混入**（表演型 vs 自发型分布偏移已被 Exp4 证实），而是：
1. **Phase 1 分布基线**：用 C-BESD 的 4 类（angry/happy/neutral/sad 各 ~700）建立"理想情况下每类情绪应该是什么样的声学基线"
2. **Phase 3 域外验证**：模型训练完成后，在 C-BESD 测试集上评估——如果混合数据训练的模型在 C-BESD 上也表现良好（比如 WA > 70%），则说明模型学到了跨数据集的泛化能力

### 4.4 最终训练集配置

| 来源 | angry | happy | neutral | sad | 类型 |
|------|-------|-------|---------|-----|------|
| FAU 清洗 | 700 | 700 | 700 | — | 非表演型 |
| 新自发数据 | — | — | — | 700 | 非表演型 |
| **合计** | **700** | **700** | **700** | **700** | — |

**总量 2,800 条**。C-BESD 的 2,780 条作为独立的域外验证集，不参与训练。

## 5. Phase 3：训练与验证

### 5.1 对比实验设计

| 实验 | 训练集 | 测试集 | 目的 |
|------|--------|--------|------|
| 基线A | 原始 FAU（~11.6K） | FAU original test (3,389) | 当前 best（66.36%） |
| 基线B | 清洗后 FAU（2,100） | FAU original test | 验证清洗效果 |
| 主实验 | 混合数据集（2,800） | FAU original test + C-BESD test | 验证跨数据集泛化 |
| 对照C | C-BESD only（1,851） | C-BESD test | 表演型基线（92.78%） |
| 对照D | C-BESD only | FAU test | 零样本（19.56% 参考） |

### 5.2 评价指标

- WA / UAR（标准）
- 每类 recall/precision（尤其是 sad 和 angry）
- FD(训练集, 测试集) —— 训练前后对比
- APC_wav / APC_delta（韵律-注意力一致性）

### 5.3 预期结果

如果方案成功：
- 主实验 FAU WA 应 > 基线A（分散了 neutral 优势 + 补充了 sad）
- 主实验 C-BESD WA 应 > 基线D（虽未用 C-BESD 训练，但 4 类均衡可能提升泛化性）
- angry/happy recall 应有明显提升（neutral 不再压倒性主导）

## 6. Phase 4：跨数据集音频标准化

### 6.1 统一预处理管线（已有，无需修改）

```
原始音频 → 16kHz 单声道重采样 → peak normalization → 4s 截断/填充
```

### 6.2 说话人划分

- MD5 hash 确定性划分
- 70/15/15 train/val/test
- 说话人零重叠

### 6.3 跨语料对齐（待实施）

- 如果多个自发数据集的录音条件差异大（麦克风、背景噪声、采样率等），考虑：
  - 频谱归一化（per-sample 均值-方差归一化）
  - 或使用 WavLM 本身的特征空间作为对齐手段（在 FD 监控下判断是否需要额外对齐）
