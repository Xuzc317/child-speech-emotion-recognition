## P0-1: C-BESD → IEMOCAP 零样本 (ExpX)

**目的**: 补全 FD=7.20 的零样本 floor 值

**命令**:
```bash
python src/train.py \
  --train_data c-besd --test_data iemocap \
  --pooling_type prosody_guided --reg_profile default \
  --seed 42 --exp_name exp_zeroshot_cbesd2iemocap
```
**预期**: WA 22-28% | **输出**: `results/logs/exp_zeroshot_cbesd2iemocap.json`

## P1-2: Exp2 多种子 (seeds 123, 456)

**目的**: Prosody 91.30% 的稳健性 + Δ=-1.48pp 显著性

**命令**:
```bash
python src/train.py --train_data c-besd --test_data c-besd \
  --pooling_type prosody_guided --seed 123 --exp_name exp2_prosody_s123
```

## P1-3: 全量 APC 计算 (C-BESD 540 条 test)

**是什么**: APC (Attention-Prosody Correlation) = 注意力权重与 RMS 能量的 Pearson r。当前仅 1 条样本 (APC_wav=0.718, APC_delta=-0.144)，需扩展到 540 条。

**命令**:
```bash
python scripts/compute_apc_full.py \
  --checkpoint checkpoints/exp2_prosody_guided/best_model.pt \
  --dataset c-besd --split test --seed 42
```
**输出**: `results/logs/apc_full_test.json` (540 条各自的 APC_wav, APC_delta, mean±std)
