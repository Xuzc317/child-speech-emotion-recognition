## 1. 设计概览

### 研究框架

本项目构建分布偏移诊断框架 (FD-WA)，系统验证「分布偏移→性能下降」的因果关系。

### 核心架构

```
WavLM Base (frozen/unfrozen) → 12层 LayerFusion → Pooling → SEMLP 分类器
                                (learnable weights)   (mean/self_attn/prosody)  (~704K params)
```

### 分歧根本原因

多处分歧同源: **launch 脚本相对设计欠 specified** — 设计意图中明确的参数因脚本未传递而落回 `src/train.py` 的代码默认值。
因此实验条件以 launch 脚本实际传递的参数为准，非以设计文档的文字描述为准。

## 4. 特殊说明

### 数据划分
- `data_split_seed=42` 固定 (说话人独立 MD5 hash, 70/15/15)
- 所有 7 个 launch 脚本均显式传递 `--data_split_seed 42`

### 训练配置
- 统一: epochs=100, patience=15
- B1: batch_size=32 (vs 设计 16)
- B2-B4, B6-B7: batch_size=16
- B5: batch_size=8 (设计 §4 L100 已预见显存减半)
- 微分学习率 (B5 unfreeze): backbone 1e-5, head 3e-4
- B7 fine-tune lr=3e-4 (代码默认; 设计建议 1e-4)

### reg_profile 机制
- `default`: weight_decay=1e-3, label_smoothing=0.1, pooling_dropout=0.0, grad_clip=None
- `fau`: weight_decay=5e-3, label_smoothing=0.15, pooling_dropout=0.3, grad_clip=1.0
- B1/B3/B4/B5/B6/B7 均显式传递 `--reg_profile` (FAU 训练用 fau)
- B2 的 `run_zs()` 未传递 → 全部 18 个零样本实验用 default
  - 影响: E3-07~12 (FAU 为源域) 训练正则化不足

### B2 跨语料类空间对齐
- C-BESD 域内 6 类, 跨语料强制对齐为 4 类 (丢弃 disgust/fear)
- 使用 `c-besd-4cl` 数据集子集

### B7 迁移
- IEMOCAP 源 = E1-09 (prosody_guided) 而非 E1-08 (INVALID)
- Fine-tune 阶段统一 `--pooling_type self_attention`, 源池化头不参与迁移
- 微调 lr=3e-4 (代码默认) vs 设计建议 1e-4
