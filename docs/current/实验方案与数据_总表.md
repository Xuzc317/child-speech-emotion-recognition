## 指标说明：WA vs UAR

- **WA (Weighted Accuracy)**：整体准确率，每个样本权重相等（即 sklearn `accuracy_score`）。
- **UAR (Unweighted Average Recall)**：先计算每个类别的 recall，再对类别取平均，每个类别权重相等，不受类别样本数不均衡影响。
- **差距来源**：FAU Aibo 类别严重不均衡（Neutral 占比最大，N=10,967 vs A=1,492/P=889/R=1,267），WA 被多数类主导。按 `test_data` 分组统计的 WA−UAR 差距（当前 192 个日志文件 post-fix 数据）：FAU Aibo **21.15pp**（69 个文件，类别不均衡）、C-BESD **0.43pp**（69 个文件，类别均衡，<1pp）、IEMOCAP **4.88pp**（54 个文件，轻度不均衡），详见 `权威数据手册.md` §「WA-UAR by Corpus」"By test_data" 表。引用文档需明确标注究竟引用哪个指标，避免 FAU 结果被高估。
  > ⚠️ **数据源订正**：此数字此前曾引用 `validation/INDEPENDENT_REVIEW.md`（给出 C-BESD 0.35pp / IEMOCAP 4.93pp）。该文档生成于 2026-06-22 13:51，早于 E1-08_s42/E4-04_s42/E4-10_s42/E4-10_s123/E4-12_s123 五个 seed 文件于同日完成的重跑修复（`权威数据手册.md` 于 2026-06-23 16:41 重生成，已是 post-fix 数据），数字已过期。已用相同算法对当前 192 个 JSON 重新计算并与 `权威数据手册.md` 表格核对一致，现以 `权威数据手册.md` 为唯一权威来源。
  > ⚠️ **该 gap 数字此前曾出现手册表格（0.43pp）与正文（0.3pp）不一致**，已于 2026-06-24 通过 `regen_handbook.py` 把正文改为引用同一 gap 变量根除，两次重生 `git diff` 为零。保留此注释作为审计线索。

## 1. 设计概览

### 研究框架

本项目构建分布偏移诊断框架 (FD-WA)，系统验证「分布偏移→性能下降」的因果关系。

### 核心架构

```
WavLM Base (frozen/unfrozen) → 12层 LayerFusion → Pooling → SEMLP 分类器
                                (learnable weights)   (mean/self_attn/prosody)
SEMLP分类器(6类593,574/4类593,316) + Pooling(111,105) + LayerFusion(12)
  = head共704,691(6类C-BESD) / 704,433(4类FAU/IEMOCAP/跨语料)
```

### 参数量明细

| 模块 | 参数量 | 说明 |
|------|--------|------|
| WavLM backbone | 94,381,936 | frozen 时 0 trainable；unfreeze 时全部计入 trainable |
| LayerFusion (weighted) | 12 | 12 层 softmax 归一化权重，可学习 |
| Pooling (self_attention) | 111,105 | 4 层 MLP：768→116→100→100→1，纯 SSL 特征驱动 |
| Pooling (prosody_guided) | 111,105 | prosody_proj(2→64→64) + attn(832→128→1)，融合 F0+energy |
| Adapter（可选, 当前未启用于主线） | 297,408 | scale+bias+gate 机制，B6 消融显示无正面贡献 |
| SEMLP 分类器（6 类） | 593,574 | 768→512(BN)→SE(r=16)→256(BN)→128→6 |
| SEMLP 分类器（4 类） | 593,316 | 同上，仅末层 128→4 |
| **Frozen 可训练总计（6 类 C-BESD）** | **704,691** | LayerFusion(12)+Pooling(111,105)+SEMLP(593,574) |
| **Frozen 可训练总计（4 类 FAU/IEMOCAP/跨语料）** | **704,433** | LayerFusion(12)+Pooling(111,105)+SEMLP(593,316) |
| **Unfrozen 可训练总计（6 类）** | **95,086,627** | 704,691 + WavLM backbone 94,381,936 |
| **Unfrozen 可训练总计（4 类）** | **95,086,369** | 704,433 + WavLM backbone 94,381,936 |

> 数据来源：`src/models/{pooling,semlp,layer_fusion,adapter,ssl_backbone}.py` 逐层手算 + `docs/discussion/讨论纪要_解冻WavLM效果分析与FAU重标注方案.md`（WavLM backbone 实测参数量）。

### B3 (E4) — 数据增强敏感性

**设计**: 4 augment conditions (C1 baseline, C2 external, C3 child, C4 mixed) × 3 datasets. 12×3=36 runs.

**C1-C4 完整定义**（源码定位：语料混合判断逻辑：`src/train.py:28,31-65`（`_resolve_train_datasets`, `_AUG_DATA_MIX_CONDITIONS`）；波形增强开关调度：`src/data/dataset.py:27-62`；SafeAWGN底层实现(SNR采样/触发概率)：`src/augmentation/safe_augmentation.py:38-41`）：

- **C1 干净基线**：无任何处理。
- **C2 成人数据混合 (机制A)**：训练集拼接完整的跨域数据集，无波形扭曲。C-BESD/FAU 训练组混入 IEMOCAP（成人数据）；**IEMOCAP 训练组例外**——改混入 FAU 儿童自发语音数据（因 IEMOCAP 本身是成人数据，混入成人数据无意义，`scripts/launch_b3.sh` 注释："C2 uses FAU mixing (adult data + child spontaneous = max shift)"）。
- **C3 儿童约束增强 (机制B)**：SafeAWGN，SNR 10-20dB，施加概率 0.5。刻意**不加 pitch shift**（避免越过儿童 F0 边界，儿童音高变化范围比成人窄，±3 semitone 已接近成人男女差距 4.3 semitone）、**不加 time stretch**（时间拉伸扭曲情感韵律标签的风险最高，参考 Tao et al., 2025, *Entropy*）。
- **C4 极端条件 (机制A+B)**：数据混合（混入对象规则同 C2）+ AWGN（SNR 5-15dB，`apply_prob=1.0`，必定触发）+ pitch shift（独立50%概率触发；触发时偏移量从 Uniform(-12,+12) 半音连续随机采样，非固定±12，`src/data/dataset.py:52-57`）。**AWGN 与 pitch shift 是两个相互独立的随机机制**（不同的触发概率、不同的随机源），不应混为一谈。

> ⚠️ **C2/C4 混合比例订正**：`实验设计方案_v3_含学习笔记.md` 原设计意图是"随机采样 IEMOCAP 样本，混合比≈1:0.5"，但实际代码 `train.py:_resolve_train_datasets()` 的实现是**整库拼接（无任何子采样/比例控制）**——`dataset_names` 直接 append 完整的跨域数据集名，`data_loader.py` 的 `UnifiedSERDataset` 据此加载两个语料的**全部** train split 样本并直接拼接。即实际混合比例由两数据集的训练集自然规模决定，并非固定的 1:0.5，且随迁移方向不同而不同（C-BESD/FAU 各自体量远小于 IEMOCAP 或 FAU，方向间比例差异显著）。这是新发现的设计-执行分歧，本报告不在此处编造具体比例数字，已建议补入 §3 设计-执行分歧表（D-NEW-4）。

### B4 (E5) — LayerFusion 消融

**设计**: 6 multi-seed experiments (last/weighted × 3 datasets) + 3 grid search (best_single L1-L12 × 3 datasets). 18+36=54 runs.

**三种 Fusion 策略定义**（源码：`src/models/layer_fusion.py`, `src/train.py`）：
- **last**：固定只使用 WavLM 第 12 层（最后一层）的输出，不引入额外参数。
- **best_single**：网格搜索逐层测试 L1-L12，选当前数据集下单层效果最好的那一层；层一旦选定即固定使用，不引入额外参数，但搜索过程本身需要 12 次独立单层训练（仅 1 seed）。
- **weighted**：12 层加权求和，权重为可学习参数 `nn.Parameter(torch.ones(12)/12)`，经 softmax 归一化，随训练更新——三者中**唯一参数化**的策略，对应 LayerFusion 模块固定的 12 个可学习参数。

- **C2/C4 的 val/test 集同样被跨域混合，非仅训练集**：`get_dataloaders()`（`src/data/data_loader.py`）对 train/val/test 三个 split 均使用同一份已混合的 dataset_names 构造数据集（`src/data/dataset.py:356-357,392-403`）。即 E4-02/04/06/08/10/12（C2/C4 各方向）报告的 WA/UAR 是在混合测试集（同时含目标域+混入域测试样本）上计算的，不是干净的单一目标域测试集。C2/C4 与 C1/C3 的评估口径因此不完全一致——WA/UAR 下降可能部分来自评估分布本身改变，而非纯粹的训练分布偏移导致泛化下降。后续撰写论文时需明确此限制，不应暗示评估目标域在 C1-C4 间保持不变。
