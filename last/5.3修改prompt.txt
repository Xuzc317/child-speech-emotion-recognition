  核心瓶颈：约 40% 的帧是零填充（平均语音 2.5s，固定窗口 4s），这些零帧参与了 attention softmax，稀释了真正情感帧的权重。                       
                                                                                                                                                
  ---
  二、A3 可优化的方向（按投入产出比排序）
                                                                                                                                                
  优先级 1：修复 Padding Mask（预计 +1~3pp）

  collate_fn_ssl_features 已经生成了 mask，但训练循环和 pooling 层都完全忽略它。零填充帧以 0 值参与 attention softmax，约 40%
  的注意力权重浪费在空白帧上。

  改动量极小：在 TemporalImportancePooling.forward 加一个 mask 参数，softmax 前把无效帧置 -inf。这是最有把握的提升。

  优先级 2：多层 SSL 特征融合

  当前只用了 WavLM 的最后一层（第 12 层）。但研究表明，不同 Transformer
  层编码不同粒度的信息——低层更偏声学（与韵律直接相关），高层更偏语义。用一个可学习的 layer-wise weighted sum 融合多层特征，让 Prosody Pooling
  在更丰富的特征空间里工作。

  优先级 3：韵律特征增强

  当前只用 F0 + energy（2 维）。可以加入：
  - Voice probability（区分有声/无声帧，排除静音帧干扰）
  - Harmonic-to-noise ratio（HNR，反映声音质量）
  - Jitter / Shimmer（微小的音高/振幅扰动，与情绪唤起相关）

  这些特征是 SER 领域的标准操作，几乎零成本。

  优先级 4：SpecAugment on SSL Features

  代码里 SpecAugment 是个空壳（forward 直接 return x）。在 SSL 特征空间（不是原始波形）上做 time masking 和 frequency masking，是 WavLM/HuBERT
  时代的标配做法，可以提升模型鲁棒性而不破坏情感信息。

  三、将项目推向更高科研贡献度的路径

  这个项目目前的方法贡献是扎实的，但叙事上限在于："一个更好的池化方法在儿童 SER 上提升 2.24pp"——这能发普通会议但上不了顶会。

  以下三条路径可以显著拔高科研贡献度：

  路径 A：可解释性深度挖掘（最推荐，改动最小）

  现在项目只报告了 "Prosody Pooling 比 mean pooling 好 +2.24pp"，但没回答为什么。

  做一个深度的可解释性分析：
  - 按情绪类别可视化注意力权重：ANGER 的 attention 是否集中在高能量帧？SAD 是否集中在低 F0 帧？用 assets/figures/confusion_matrix_A3.png 的
  per-class 数据配合 attention 热力图
  - 跨语言对比：同样的情绪（如 ANGER），英语儿童和泰卢固语儿童的 attention
  模式是否一致？如果不一致，说明韵律-情绪的映射受语言调节——这是一个新发现
  - 与成人对比：同样的 Prosody Pooling 在成人数据 (IEMOCAP)
  上是否也有类似增益？如果增益小得多，说明"儿童语音更需要韵律引导"——这才是你论文最核心的论点

  科研贡献升级：从"我们提了一个新池化方法"升级为"我们发现儿童语音的情绪信息在时间维度上的分布规律，并提出利用该规律的方法"。

  路径 B：跨语言分布偏移——从 Limitation 变成 Contribution

  当前跨语言结果（English→Telugu 19.68%）被论文当作"局限性"一笔带过。但这其实是全文最有冲击力的发现：

  语言偏移 > 声学偏移：
    同语言内 A1→A3: +2.24pp（声学校准）
    跨语言 X1: 81% → 20%（语言鸿沟，-61pp）

  这揭示了一个更深刻的规律：分布偏移是多维度的，语言是比年龄/声学更严重的维度。当前方法（Prosody
  Pooling）能弥合年龄偏移，但完全无法应对语言偏移。

  可以补充的实验：
  - 语言对抗训练：在 WavLM 特征上加一个语言分类器 + 梯度反转层，迫使特征对语言不敏感
  - 分析为什么失败：英语和泰卢固语的 F0 分布、能量分布有何差异？是否是语言特有的韵律模式导致了 attention 失效？

  科研贡献升级：从"单语儿童 SER 方法"升级为"儿童 SER 中分布偏移的多维度框架（年龄 + 语言 + 增强），揭示各维度的相对严重性"。

  路径 C：修正 FD 计算 + 完整分布偏移理论

  代码里 compute_adapter_init.py 的 FD 计算有 bug——只算了均值差的平方范数，缺协方差项。正确的 FD 在 constrained_aug.py 里。论文第 3 章引用的
  "FD=0.37" 实际上不完整。

  修正后可以构建一个统一的"分布偏移-性能退化"理论框架：
  FD(儿童 vs 成人)  = 0.XX  → 解释为什么需要 SSL 特征
  FD(C2 增强)       = 9.87  → 解释为什么增强有害
  FD(泰卢固语 vs 英语) = ???  → 解释为什么跨语言失败

  把这三个层面的 FD 放在同一张图里，形成全文最有说服力的论点：分布偏移可量化预测分类退化，且偏移来源（声学/增强/语言）决定了退化程度。

一、先明确本次选定方案

我们现在采用的最终数据划分协议是：

仍然保持传统的 7:3 训练/测试划分，但为了避免 test-as-val 数据泄露，在 70% 训练说话人内部再划出验证说话人用于 early stopping。也就是：

1. 外部 speaker-independent 7:3：
   - 70% speaker 作为 trainval
   - 30% speaker 作为 final test
2. 内部从 trainval 中划分 validation：
   - 从 70% trainval speaker 中再划出一部分 speaker 作为 val
   - 推荐比例：trainval 内部 85% train / 15% val
   - 最终大约为 train 59.5%、val 10.5%、test 30%
3. adapter_init 的儿童统计量只能用真正 train speaker 计算，不能使用 val speaker，更不能使用 test speaker。
4. val 只用于 early stopping、模型选择和超参选择。
5. test 严格 hold-out，训练中完全不可见，只在最终评估时使用一次。
6. 禁止 test set = val set。
7. 禁止使用 test speaker 计算任何统计先验、normalization、adapter_init、早停或调参信息。

请把原先“第二次数据泄露修复方案”从 60/20/20 三路划分，统一修正为上述“外部 7:3 + 内部 val”的协议。注意：本质是三集合 train/val/test，但论文表述上可以写成传统 7:3：先 7:3，再从训练侧划验证集。

任务 2：重新整理模块 1、2、3 的方案叙事

请把最终方案收缩并讲清楚：

最终推荐方法应该是两个真正的方法模块：

- 模块 1：Acoustic Calibration Adapter
- 模块 2：Prosody-guided Temporal Importance Pooling

模块 3 不再作为“提升性能的方法模块”来讲，而改为实验章节中的：
- Distribution Shift Sensitivity Analysis
- 或“增强敏感性负面实验”
- 或“分布偏移导致分类退化的负面实验”

原因：
当前实验中“无增强”效果最好，儿童约束增强、成人参数增强、极端增强都导致明显下降。因此不能把模块 3 讲成“我们提出了有效增强方法”。正确讲法是：这个实验说明儿童语音的情绪线索对 pitch shift/time stretch 等波形增强非常敏感，盲目增强会引入分布偏移并导致性能退化。最终推荐模型不使用增强。

请在论文和文档中统一这个逻辑：

1. 模块 1 的直白解释：
   - WavLM 是成人语音预训练模型。
   - 儿童语音进入 WavLM 后，帧级特征存在域偏移。
   - Adapter 放在 WavLM 输出后，对每一帧的 768 维特征做轻量校准。
   - 它不改变时间长度，不直接分类，只让儿童语音特征更适合后续情绪识别。
   - 可以用一句话讲：模块 1 解决“每一帧的特征对不对”。

2. 模块 2 的直白解释：
   - WavLM 输出 200 帧特征，分类器需要整句向量。
   - 简单 mean pooling 会把所有帧一视同仁。
   - 儿童语音情绪信息往往集中在音高/能量变化明显的帧。
   - 因此用 F0 和 energy 引导 attention，给关键帧更大权重。
   - 可以用一句话讲：模块 2 解决“哪些帧更重要”。

3. 模块 1 和模块 2 的关系：
   - WavLM：提取真实时间轴上的帧级特征。
   - 模块 1：校准每一帧特征。
   - 模块 2：选择/加权更重要的时间帧。
   - DrseNet：最终分类。
   - 这比“三模块并列”更清楚。

4. 模块 3 的新定位：
   - 不作为最终方法模块。
   - 放到实验章节。
   - 标题建议：“增强敏感性分析：分布偏移导致分类退化”。
   - 明确回答“无增强更好，为什么还要做增强实验？”：
     实验目的不是为了证明增强提升性能，而是为了证明成人 SER 中常用增强不能直接迁移到儿童 SER；FD 越大，准确率越低，说明增强引入的分布偏移可以解释性能退化。
   - 最终推荐模型应明确写“不使用波形增强”。
